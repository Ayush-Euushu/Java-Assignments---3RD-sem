# 25CSE095 - Java Programming Coursework

This repository contains my laboratory and home assignment submissions for the course **25CSE095**. The codebase tracks my progress from foundational syntax to object-oriented programming paradigms, file operations, and software structure.

## 📂 Repository Architecture

The project workspace is organized sequentially into dedicated assignment directories:

### 🧩 Foundational Modules
*   **`A1/` to `A3/` - Core Logic & Syntax Basics**
    *   Basic I/O operations, variable configurations, and data types.
    *   Conditional execution, branching mechanisms, and fundamental loop controls.
    *   Direct array management (sorting, binary searching) within single-method flows.

### 🏛️ Object-Oriented Principles
*   **`A4/` to `A6/` - Classes & Encapsulation**
    *   Modular system styling using methods and user inputs (character validation, calendar calculators).
    *   Constructors, access modifiers, and internal variable masking.
*   **`A7/` to `A9/` - Advanced OOP Inheritance & Structures**
    *   Hierarchical designs including base-level abstractions and class extensions.
    *   Real-world modeling implementations (e.g., Vehicle behaviors, Banking structures, and Geometric properties).
    *   Polymorphic overrides, runtime dispatch, and abstract interfaces.

### ⚙️ Extended Implementations
*   **`A10/` & `A11/` - Operations & Production**
    *   Structured exception wrappers and application stabilization.
    *   File management pipelines and data parsing blocks.
    *   Final package distributions and automated workflows.

*Note: All compiled bytecode artifacts (`*.class`) are actively ignored using the `.gitignore` setup to retain clean workspace builds.*

## ⚙️ Compilation and Execution

To compile and execute any application locally via Git Bash, hop into the specific assignment subfolder and invoke the Java Development Kit (JDK) commands:

```bash
# Navigate to the chosen subfolder
cd A1

# Compile the target source file
javac A1a.java

# Run the compiled bytecode execution
java A1a
```
